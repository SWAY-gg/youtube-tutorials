# Discord-боты на Python — курс Sweet1e42

Исходный код к урокам с YouTube-канала **[Sweet1e42](https://www.youtube.com/@sweet1e42)**. В курсе мы с нуля пишем Discord-ботов на Python и библиотеке [disnake](https://github.com/DisnakeDev/disnake), начиная с первых слэш-команд.

## Где найти исходники

**Весь код к каждому эпизоду лежит в [Releases](../../releases).**

Один эпизод — один релиз. В каждом релизе есть архив с готовым проектом: код из видео, `requirements.txt`, `.env.example` и README с пошаговой инструкцией.

Как скачать:

1. Откройте вкладку [Releases](../../releases) справа на странице репозитория.
2. Найдите нужный эпизод.
3. В блоке **Assets** скачайте архив с проектом.
4. Распакуйте архив и следуйте README внутри.

## Важно про токен

Токен бота — это пароль от него. Храните его в файле `.env` и никогда не выкладывайте в открытый доступ. Если токен утёк, сразу сбросьте его в [Discord Developer Portal](https://discord.com/developers/applications) кнопкой **Reset Token**.
